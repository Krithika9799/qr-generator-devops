# QR Generator - DevOps Project

A simple QR Code Generator web application built with Python Flask and containerized using Docker.

This project demonstrates a practical DevOps workflow using GitHub, Docker, Jenkins, and Kubernetes/Minikube.

## 🚀 Project Overview

The application allows users to enter a URL and generate a QR code.

The project focuses on deploying and managing a web application using DevOps tools and practices.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Application development |
| Flask | Web application framework |
| QR Code | QR code generation |
| Git | Version control |
| GitHub | Source code management |
| Docker | Containerization |
| Jenkins | CI/CD automation |
| Kubernetes | Container orchestration |
| Minikube | Local Kubernetes environment |
| kubectl | Kubernetes management |
